# AI_Email_Generator
An AI-powered Email Generator built using Java Spring Boot, React + Vite, and a Chrome Extension to simplify email composition and generate professional email replies efficiently.

# Email Generator

Email Generator is a full-stack application designed to simplify email writing using AI. It provides an intuitive React-based user interface, a Java Spring Boot backend for handling application logic and API requests, and a Chrome Extension for convenient access to email-generation functionality directly from the browser.

### Tech Stack
- **Backend:** Java, Spring Boot
- **Frontend:** React.js, Vite, JavaScript
- **Browser Extension:** Chrome Extension
- **API Testing:** Postman

### Key Components
- Spring Boot backend for processing requests.
- React + Vite frontend for user interaction.
- Chrome Extension for browser-based email generation.

### Objective
To make email composition faster, easier, and more efficient by helping users generate professional email content.
